# useQueryParams

Lee y escribe parámetros de URL con tipado completo. Se mantiene sincronizado automáticamente con la navegación del navegador (atrás / adelante).

## Firma

```ts
function useQueryParams<TQuery extends Record<string, any>>(): {
  get: (...keys: (keyof TQuery)[]) => Partial<TQuery>;
  set: (params: Partial<TQuery>, url?: string) => void;
  build: (params: Partial<TQuery>) => string;
  pathname: string;
  search: string;
  clear: () => void;
}
```

## Parámetro de tipo

Definí la forma de tus query params como genérico para obtener autocompletado y acceso tipado:

```ts
interface Filtros {
  pagina: number;
  q: string;
  activo: boolean;
}

const { get, set } = useQueryParams<Filtros>();
const { pagina, q } = get("pagina", "q");
set({ pagina: 2 });
```

## Valor de retorno

| Método / Propiedad | Descripción |
|--------------------|-------------|
| `get(...keys)` | Devuelve un objeto con los params solicitados, haciendo auto-cast a `boolean`, `number` o JSON parseado |
| `set(params, url?)` | Reemplaza todo el query string por `params` (`history.replaceState`). Conserva el hash. Opcionalmente apunta a otro path. `set({})` elimina el query string |
| `build(params)` | Devuelve un query string a partir de `params` sin navegar. Ignora `null`/`undefined` y serializa objetos y arrays como JSON |
| `pathname` | `location.pathname` actual |
| `search` | `location.search` actual |
| `clear()` | Elimina todos los query params de la URL, conservando el hash |

`pathname` y `search` son reactivos. Todos los componentes que usan el hook se vuelven a renderizar después de `set`, `clear` o la navegación atrás/adelante del navegador.

## Auto-conversión de valores

`get()` convierte automáticamente los valores del string de la URL:

| Valor en string | Convertido a |
|-----------------|--------------|
| `"true"` / `"false"` | `boolean` |
| `"null"` | `null` |
| `"42"`, `"-1.5"` | `number` |
| `'{"a":1}'`, `"[1,2]"` | Objeto/array parseado |
| `"007"`, `"0x10"`, `"1e5"`, enteros no seguros | `string` (sin cambios) |
| Cualquier otra cosa | `string` |

## Ejemplo

```tsx
import { useQueryParams } from "@julianfere/hooked";

interface ParamsBusqueda {
  q: string;
  pagina: number;
  activo: boolean;
}

function PaginaBusqueda() {
  const { get, set, clear } = useQueryParams<ParamsBusqueda>();
  const { q = "", pagina = 1 } = get("q", "pagina");

  return (
    <div>
      <input value={q} onChange={(e) => set({ q: e.target.value, pagina: 1 })} />
      {/* set() reemplaza el query string, así que conservá los params que necesites */}
      <button onClick={() => set({ q, pagina: pagina + 1 })}>Siguiente página</button>
      <button onClick={clear}>Limpiar filtros</button>
    </div>
  );
}
```

:::note
Durante el renderizado en el servidor, `pathname` y `search` son strings vacíos. `get`, `set` y `clear` usan `window`, así que llamalos solo en el cliente (en event handlers o efectos).
:::
