# useDelay

Ejecuta un callback tras un retardo configurable. Soporta ejecución automática al montar y modo de disparo manual.

## Firma

```ts
// Modo automático
function useDelay(
  callback: () => void,
  options?: { delay?: number; manual?: false }
): () => void;

// Modo manual
function useDelay(
  callback: () => void,
  options: { delay?: number; manual: true }
): () => () => void;
```

## Opciones

| Propiedad | Tipo | Por defecto | Descripción |
|-----------|------|-------------|-------------|
| `delay` | `number` | `250` | Milisegundos antes de que se ejecute el callback |
| `manual` | `boolean` | `false` | Cuando es `true`, el hook devuelve una función de disparo en lugar de auto-ejecutarse |

## Valor de retorno

| Modo | Retorno | Descripción |
|------|---------|-------------|
| `manual: false` | `() => void` | No-op (se auto-ejecuta al montar) |
| `manual: true` | `() => () => void` | Llamala para programar el callback. Devuelve una función que cancela esa ejecución |

- El callback siempre se ejecuta con su última versión, así que podés usar funciones inline.
- En modo automático, el timer se reinicia cuando cambia `delay`.
- Los timers pendientes, en los dos modos, se limpian cuando el componente se desmonta.

```ts
const ejecutar = useDelay(guardar, { delay: 1000, manual: true });

const cancelar = ejecutar(); // programa guardar() en 1 s
cancelar();                  // cancela esa ejecución
```

## Ejemplo interactivo

<HookPlayground
  previewHeight={260}
  code={`import { useState } from "react";
import { useDelay } from "@julianfere/hooked";

export default function App() {
  const [message, setMessage] = useState("Esperando…");

  const trigger = useDelay(
    () => setMessage("¡Se disparó después de 1 segundo!"),
    { delay: 1000, manual: true }
  );

  return (
    <div style={{ padding: 24, fontFamily: "sans-serif" }}>
      <p>{message}</p>
      <button onClick={() => { setMessage("Esperando…"); trigger(); }}>
        Disparar (1 s de retardo)
      </button>
    </div>
  );
}`}
